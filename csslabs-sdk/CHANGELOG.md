# Changelog

## 0.1.0

- First release of the CSS Labs Android SDK.
- Hash-chained, append-only local log with verification, export and export check.
- Opt-in device signals: accessibility services, notification access, device administrators, user-installed certificates, VPN and proxy, developer options and USB debugging, audio and camera in-use counts.
- Consent layer: everything off by default, revocable, logged.
- Change flags between readings, in plain language.
- CC and SS layer: the framework's geometric-mean formula and a scoring interface. No scoring functions and no threshold ship with the SDK.
- No INTERNET permission and no network dependency.
